Metrics reference

Every number on the card, what it means and where it comes from. All GitHub data is public; a token only raises rate limits and adds all-time accuracy.

How data is collected

SourceUsed for
GitHub RESTName, avatar, public repositories, total stars, followers.
GitHub GraphQL (needs token)All-time contributions, streaks, reviews, repositories contributed to, forks, discussions.
Public fallback (no token)Contributions from a public calendar API; PRs/issues from the GitHub search API.

Contributions, streaks and trophies are aggregated across all years, not just the last one.

Freshness: responses are cached for 30 minutes (production) / 5 minutes (development), and GitHub's image proxy caches the rendered card too — so a card is at most ~30 minutes stale.

Contribution Activity

Daily contributions for the last 30 days. Rendered as bars (Classic), a smoothed area line (Modern) or a heat strip (Grid) depending on the card style.

Top Languages

The primary language of each public repository, counted per repo and topped to 5. The percentage is the share of counted repos — it is not a code-volume breakdown (unlike GitHub's own language bar).

Private data

Cards only see public data unless the deployment has GitHub OAuth configured. When it does, the studio shows a Connect GitHub button. Authorizing lets the card include your private repositories and private contributions.

StepWhat happens
ConnectThe studio keeps a random user_key in your browser and sends you through GitHub's consent screen.
StoreThe server exchanges the code for a token, encrypts it (AES-256-GCM) and stores it against the user_key.
EmbedThe user_key — never the token — is added to the card URL.
RenderThe server loads the token and fetches private repos and private contribution counts for your account.
Safety: a user_key is only honored when the username in the URL is the account that granted it, so sharing a card URL never exposes another user's private data. Disconnecting revokes the authorization on GitHub.

Setup (three environment variables plus MongoDB and an encryption key) is covered in the README. Without it the feature stays hidden.
